Flagship Suite

SmartDictionary Pro

A modular, production-ready collection framework engineered specifically to resolve Unity's serialization limitations with zero performance penalty.

SerializableDictionary

Base dictionary with zero event overhead and clean YAML serialization. Features safe access methods (TryAdd, GetOrDefault, AddOrUpdate).

Pure Base • Zero Allocations

ObservableDictionary

Reactive subclass with C# Action delegates, serialized UnityEvent fields, and runtime EventsEnabled toggle for wire-free UI architecture.

Reactive • Action + UnityEvent

OrderedDictionary

Maintains deterministic insertion order while preserving O(1) hash lookup. Supports GetAt(index), MoveToFront, and MoveToBack.

Order Preserved • Reorderable

BiDictionary

Two-way bidirectional mapping with O(1) forward (Key → Value) and reverse (Value → Key) lookups without linear scanning.

Two-Way • Dual Hash Map

SerializableHashSet

High-performance unique set with automatic duplicate rejection. Backed by IEquatable value comparison for custom classes.

Unique Set • Deduplication

ObservableHashSet

Reactive unique set emitting OnItemAdded and OnItemRemoved events. Ideal for hero rosters, tag registries, and achievement unlocks.

Reactive Set • Event Driven

SerializableStack

LIFO stack collection serializing top-first into Unity scenes. Features safe TryPop, TryPeek, and push/pop event listeners.

LIFO • Undo / Stat History

SerializableQueue

FIFO queue collection with Enqueue, Dequeue, TryDequeue, and event hooks. Perfect for matchmaking, dialog queues, and turn orders.

FIFO • Matchmaking / Actions

Quick Start Guide

Drop-in C# Integration in Minutes

1. Defining Class Keys & Struct Values C# 
using UnityEngine;
using EngineEdge.SmartDictionary;

[System.Serializable]
public class HeroStatsDatabase : MonoBehaviour
{
    // Reactive dictionary with full inspector & event support
    public ObservableDictionary<CharacterProfile, CombatStats> heroStats;

    void OnEnable()
    {
        heroStats.OnEntryAdded += (hero, stats) => 
            Debug.Log($"Hero registered: {hero} with ATK: {stats.attackPower}");
    }
}
